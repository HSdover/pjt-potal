# 거버넌스 포털 화면 설계

작성일: 2026-06-08

이 문서는 거버넌스 포털이 제공할 5개 핵심 화면의 설계 기준이다.
범위 결정(Gold만 관리)과 메타 모델은 `gold-metadata-lineage.md`를 참고한다.
배경과 비유 중심 설명은 `ai-data-governance-overview.md`를 참고한다.

## 화면 구성 개요

| 화면 | 한 줄 가치 |
|---|---|
| ① Gold 카탈로그 검색 | "어떤 자료가 있나" |
| ② Gold 상세 | "이 자료 전체 정보" |
| ③ 청크 상세 | "이 조각이 정확한가" |
| ④ AI 응답 출처 추적 (★ 핵심) | "챗봇 답변이 어디서 왔나" |
| ⑤ 컴플라이언스 대시보드 | "전체적으로 안전한가" |

---

## 화면 ① Gold 카탈로그 검색

### 한 줄로 말하면

AI용으로 가공된 자료가 뭐가 있는지 찾아보는 검색 화면. 도서관 입구의 검색대.

### 누가 쓰나

- 현업 직원: "재무 관련 AI 자료 뭐 있나"
- AI 엔지니어: "내가 만든 자료가 잘 등록됐나"
- 감사팀: "MNPI 등급 자료 전체 목록"
- 모든 사용자의 첫 진입 화면

### 화면 모양

```
┌─────────────────────────────────────────────────────────────────┐
│  Gold 자산 검색                                                 │
├─────────────────────────────────────────────────────────────────┤
│  [검색창: 키워드 또는 자연어로 입력]              [검색]        │
│                                                                 │
│  필터:                                                          │
│   도메인 ▼   등급 ▼   임베딩모델 ▼   RAG앱 ▼   소유자 ▼   상태 ▼│
├─────────────────────────────────────────────────────────────────┤
│  이름                       도메인  등급    소유자   청크  인용 │
│  ─────────────────────────────────────────────────────────────  │
│  2026 Q3 경영보고서          재무   대외비  홍길동   87   421   │
│  리스크관리 정책가이드       리스크 내부    이순신   142  203   │
│  IB부문 분기 실적자료        재무   MNPI 🔒 홍길동   56   88    │
│  신상품 ELS 약관             상품   공개    김유신   34   12    │
│                                                                 │
│                                          [1] 2 3 4 ... 다음 ▶  │
└─────────────────────────────────────────────────────────────────┘
```

### 컬럼 정의

| 컬럼 | 무슨 뜻 |
|---|---|
| 이름 | 자료 이름 (예: "2026 Q3 경영보고서") |
| 도메인 | 어느 업무 영역인지 (재무/리스크/상품 등) |
| 등급 | 공개/내부/대외비/MNPI 같은 보안 등급 |
| 소유자 | 누가 책임지는 사람인지 |
| 청크 수 | 몇 조각으로 잘려있는지 |
| 인용 수 | 최근 30일 AI가 몇 번 갖다 썼는지 |

### 핵심 기능

1. 키워드 검색: "영업이익" 같은 단어로 찾기
2. 의미 검색: "올해 실적 어땠지" 같이 풀어 말해도 찾아주기 (포털 자체가 AI 검색 사용)
3. 필터: 등급별, 도메인별, 모델별로 좁혀보기
4. 클릭 시: 화면 ②(Gold 상세)로 이동

### 사용 시나리오

> 감사팀 김차장: "MNPI 등급으로 분류된 Gold 전부 보여줘"
> → 등급 필터에서 'MNPI' 선택 → 247건 리스트 확인 → 그 중 검토 필요한 것 클릭

### 6개 정보 블록

| 블록 | 무엇을 보여주나 | 비유 |
|---|---|---|
| 가공 정보 | 어떻게 잘랐고, 무슨 AI 모델로 변환했는지 | "이 책은 어느 출판사에서 어떤 인쇄기로 찍었나" |
| 출처 | 어떤 원본 PDF에서 왔는지 | "이 책은 어떤 원고에서 만들어졌나" |
| 거버넌스 | 누구만 볼 수 있고, 언제까지 보관하나 | "누가 빌릴 수 있나, 언제까지 보관하나" |
| 품질 | 가공이 잘 됐는지 점수 | "인쇄 상태가 어떤가" |
| AI 사용 현황 | 챗봇이 얼마나 갖다 썼나 | "이번 달 몇 번 대출됐나" |
| 청크 목록 | 안에 든 조각들 | "목차" |

### 핵심 기능

1. [Dataiku Flow 보기]: 가공 작업의 기술 디테일이 궁금하면 Dataiku로 점프
2. [재처리 요청]: 모델이 바뀌었거나 원본이 갱신됐을 때 다시 만들어달라고 요청
3. [삭제 요청]: 보존 만료나 삭제 요청 (보안팀 승인 워크플로우)
4. 청크 클릭 → 화면 ③(청크 상세)로 이동

### 사용 시나리오

> 재무팀장: "내가 소유자로 돼 있는 Gold 자료 다 좀 확인해야겠다"
> → 카탈로그에서 소유자 본인 필터 → 각 자료 클릭 → 등급/내용 점검
> → MNPI 등급으로 올려야 할 자료 발견 → 등급 변경 요청

## 화면 ④ AI 응답 출처 추적 — 이 프로젝트의 핵심

### 한 줄로 말하면

챗봇이 한 말이 어느 원본에서 나왔는지 한눈에 보여주는 화면. AI 답변의 영수증.

### 왜 핵심인가

이 한 화면 때문에 거버넌스 포털이 존재한다. AI 답변에 대해 사람이 책임지고 검증할 수 있게 만드는 유일한 도구다.

### 누가 쓰나

- AI 운영자: 매일 AI 답변 품질 모니터링
- 감사: 컴플라이언스 점검 시
- 현업: 챗봇 답변이 의심스러울 때
- 임원: 보고용 답변 출처 확인

> → CHK-0042의 [원본 PDF 열기] → 87페이지 실제 표 확인 → ✓ 일치

#### 시나리오 B: 컴플라이언스 사고 대응

## 개발 우선순위

### 1차 오픈 (MVP)

| 화면 | 비고 |
|---|---|
| ① Gold 카탈로그 검색 | 식별/단계/등급/소유자/상태 (자동 수집분만) |
| ② Gold 상세 | 가공/출처/거버넌스/품질/사용현황/청크목록 |
| ④ AI 응답 출처 추적 | RAG 앱 로그 연동 필수 |

### 2차 오픈

| 화면 | 비고 |
|---|---|
| ③ 청크 상세 | 본문 미리보기 + 원본 PDF 페이지 점프 |
| ⑤ 컴플라이언스 대시보드 | MNPI/PII 일괄 분류 후 |

### 3차 오픈 (확장)

- 영향도 분석 (모델 변경, 원본 갱신, 삭제 cascade)
- 비즈니스 묶음 추상화 (도메인 분류 안정화 후)
- 임원 보고 자동화
